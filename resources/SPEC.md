# プロジェクト生成ツール 仕様書

## 1. 概要

本ツールは、複数のテンプレートリポジトリを組み合わせて、用途に応じたプロジェクト初期構成を生成することを目的とする。

対象テンプレート例：

* Python_Template
* Git_Template
* Markdown_Template
* C_template

---

## 2. 設計方針

### 2.1 責務分離

* 各テンプレートは**独立したリポジトリとして維持**
* 本ツールは**統合・生成のみを責務とする**
* テンプレートの内容には依存しない（ブラックボックス扱い）

---

### 2.2 実行環境制約

* OS標準機能で実行可能であること

  * Windows：PowerShell
  * macOS / Linux：bash
* 追加ランタイム禁止

  * Python ❌
  * Node.js ❌
* 必須依存は以下のみ

  * Git

---

### 2.3 利用形態

| モード    | 説明        |
| ------ | --------- |
| 非対話モード | 引数でテンプレ選択 |
| 対話モード  | ユーザ入力で選択  |

---

## 3. 機能要件

---

## 3.1 テンプレート選択

### 要件

* ユーザは以下を選択可能とする

```text
git
python
c
markdown
```

---

### 依存関係

| テンプレ     | 依存  |
| -------- | --- |
| python   | git |
| c        | git |
| markdown | git  |

---

### 振る舞い

* 依存は自動付与される
* 重複は除去される

---

## 3.2 テンプレート取得

### 要件

* 各テンプレートはGit経由で取得する
* shallow clone（履歴最小化）とする

---

### 非要件

* ローカルキャッシュは必須ではない

---

## 3.3 ファイル配置

### 基本ルール

1. Gitテンプレを**ベースとして適用**
2. 他テンプレを**追記・上書き**する

---

### 配置順序

```text
1. Git_Template
2. 言語テンプレ（Python / C）
3. その他（Markdown）
```

---

## 3.4 衝突検出

### 判定ルール

```text
1. ファイル未存在 → 追加
2. 完全一致 → スキップ
3. 差分あり → 衝突
```

---

### 衝突時の挙動

* 上書きは禁止（デフォルト）
* 以下を実施する

```text
<filename>.merge.<template>
```

---

### 出力例

```text
README.md.merge.python
claude.md.merge.c
```

---

## 3.5 ファイル種別ごとの処理ルール

---

### 3.5.1 機械的マージ対象

| ファイル           | 処理 |
| -------------- | -- |
| .gitignore     | 追記 |
| .editorconfig  | 追記 |
| .gitattributes | 追記 |

---

### 3.5.2 ドキュメント系

| ファイル      | 処理             |
| --------- | -------------- |
| README.md | Gitテンプレをベースに追記 |
| docs配下    | 追記             |

---

### 3.5.3 指示ファイル（重要）

| ファイル                    | 処理   |
| ----------------------- | ---- |
| claude.md               | 衝突扱い |
| copilot-instructions.md | 衝突扱い |

---

### 理由

* 意味的競合が発生するため
* 自動マージは不正確

---

## 3.6 ログ出力

### 要件

各ファイルに対して以下を出力する

```text
[ADD] file
[SKIP] file
[CONFLICT] file
```

---

## 3.7 対話モード

### 要件

* 引数未指定時に起動
* 各テンプレについて yes/no 入力

---

### 入力仕様

```text
Use Git template? (y/n)
```

---

## 3.8 非対話モード

### 要件

```bash
generate git python
```

---

## 4. 非機能要件

---

### 4.1 可搬性

* OS依存を最小化
* bash / PowerShell双方で動作

---

### 4.2 安全性

* 既存ファイルの破壊禁止（デフォルト）
* 衝突時は必ず退避

---

### 4.3 拡張性

* テンプレ追加が容易であること
* 設定ファイルで定義可能とする（任意）

---

### 4.4 可観測性

* 処理内容がログとして明示される

---

## 5. 将来拡張（任意）

---

### 5.1 dry-run

* 実行せず結果のみ表示

---

### 5.2 対話型衝突解決

```text

[2] skip
[3] show diff
```

---

### 5.3 差分表示

* unified diff形式

### 5.5 テンプレキャッシュ

* clone高速化

---

## 6. 除外事項

以下は本仕様の対象外とする：

* テンプレ内容の検証
* 自動3-wayマージ
* Git履歴の統合
* GUI

---

# 総括

本設計は以下を両立する：

* テンプレの独立性維持
* 組み合わせの柔軟性
* 環境依存の最小化
* 安全な衝突管理
