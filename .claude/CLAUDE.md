# 実装指示（Claude Code / Codex向け）

## 1. 目的

本プロジェクトは、複数のGitHubテンプレートを組み合わせて、
プロジェクト初期構成を生成する軽量スクリプトである。

実装は「単純・明示的・依存最小」でなければならない。

## 2. 絶対制約（必ず遵守）

以下を厳守すること：

### 2.1 依存関係

以下のランタイム・ツールの追加は禁止：

- Python
- Node.js
- Go
- その他任意の言語処理系

使用可能なのは以下のみ：

- bash（macOS / Linux）
- PowerShell（Windows）
- Git

### 2.2 禁止事項

以下の実装は禁止：

- GUIの実装
- HTTP通信（git clone以外）
- パッケージマネージャの利用
- 外部ライブラリの導入

## 3. 設計原則

### 3.1 責務分離

- テンプレートリポジトリは外部資産として扱う
- テンプレートの内容を変更してはならない
- 本ツールは統合処理のみを行う

### 3.2 再現性（決定性）

- 同一入力に対して同一出力を保証すること
- ランダム性を導入してはならない

### 3.3 単純性

- 複雑な抽象化は禁止
- ファイル操作は明示的に記述する
- 可読性を最優先する

## 4. ファイル処理ルール

### 4.1 衝突定義

以下を満たす場合、衝突とみなす：

- 対象ファイルが既に存在する
- 内容が一致しない

### 4.2 衝突時の挙動

以下を厳守：

- 既存ファイルを上書きしてはならない
- 必ず以下の形式で退避ファイルを生成する

<元ファイル名>.merge.<テンプレ名>

例：
- README.md.merge.python
- claude.md.merge.c

### 4.3 ファイル種別ごとの処理

#### 自動追記（機械的マージ）

- .gitignore
- .editorconfig
- .gitattributes

→ 追記する

#### ドキュメント系

- README.md

→ Gitテンプレをベースにし、他テンプレを追記

#### 指示ファイル（重要）

- claude.md
- copilot-instructions.md

→ 自動マージ禁止、必ず衝突扱い

## 5. 実行モード

### 5.1 対話モード

- 引数未指定時に起動する
- yes/no形式で選択させる

例：
Use Git template? (y/n)

### 5.2 非対話モード

- 引数でテンプレを指定する

例：
generate git python

## 6. ログ出力

すべてのファイル操作に対して以下を出力する：

- [ADD] 追加
- [SKIP] 同一のためスキップ
- [CONFLICT] 衝突

## 7. エラーハンドリング

以下の場合は即時終了：

- git clone失敗
- 不正な入力

エラーメッセージは明確に出力すること

## 8. 実装の禁止領域

以下は実装してはならない：

- 3-wayマージ
- 構文解析（AST等）
- 設定ファイルシステム（YAML/JSON）
- プラグイン機構

## 9. 出力品質

- コードは読みやすくすること
- トリッキーな書き方は禁止
- 明示的な処理を優先する

## 10. 将来拡張（今回は実装しない）

以下は対象外：

- dry-run
- diff表示
- 衝突の対話解決

※これらを勝手に実装してはならない
